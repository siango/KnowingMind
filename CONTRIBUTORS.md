# Contributors / ผู้ร่วมพัฒนา

KnowingMind recognizes contributions that are traceable to public project evidence.

## Human contributors

The authoritative public record is the GitHub commit and merged pull-request history of this repository.

Current maintainer / repository owner:
- **siango** — project maintainer and repository owner.

Additional contributors should be added after a merged public contribution, using the display name and GitHub handle they choose to publish.

## How recognition works

A person may be recognized here when at least one of these is true:
- a pull request is merged;
- a reviewed documentation, accessibility, localization, test, provenance, or source contribution is accepted;
- a material project contribution is independently documented and approved for public attribution.

Recognition is not a ranking and does not imply doctrinal authority.

## AI and software tools

AI systems and software services may assist with engineering, review, research, or operations, but they are not listed as human contributors and must not be represented as Canon or spiritual authority.
