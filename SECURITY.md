# Security Policy

## Reporting

Do not open a public issue for a vulnerability or sensitive disclosure.

Use GitHub's private vulnerability reporting for this repository when available. Otherwise contact the repository owner privately through the verified contact shown on the owner's GitHub profile.

Do not include live credentials, private user data, raw practice records, or production endpoint details in examples or public evidence.

## Public repository boundary

This repository must not contain:

- secrets or credentials
- `.env` files with live values
- private evidence
- user practice data
- private payment or donor data
- non-redistributable source files
- production infrastructure details that create security risk

Use synthetic fixtures and public-safe configuration examples only.
