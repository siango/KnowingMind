# Security Policy

## Supported scope

Security reports for the current public alpha are accepted. No production
availability or compatibility guarantee is made.

## Reporting

Do not open a public issue for a vulnerability or sensitive disclosure.
Use GitHub's private vulnerability reporting for this repository. If that
channel is unavailable, contact the repository owner privately through the
verified contact shown on the owner's GitHub profile.

Do not include live credentials, private user data, raw practice records, or
production endpoint details in examples or public evidence.

## Public-alpha boundaries

The repository must not contain secrets, `.env` files, credentials, private
evidence, raw PDFs, ZIP archives, user practice data, or production endpoint
details. Use synthetic fixtures only.
