# Public / Private Boundary

## Public

Suitable for this repository after review:

- public application code
- public API/interface contracts with no secrets
- documentation
- synthetic fixtures
- tests
- localization files
- contribution templates
- public architecture descriptions
- citation/provenance tooling

## Private or excluded

Do not publish:

- credentials or secrets
- production environment dumps
- private runtime evidence
- private user practice records
- private donor/payment details
- restricted or non-redistributable source material
- private infrastructure topology that creates security risk
- files with unclear rights or UNKNOWN classification

## Fail-closed rule

If a file's classification or rights are unclear, keep it out of the public repository until reviewed.
