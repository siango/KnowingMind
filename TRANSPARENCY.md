# Transparency / ความโปร่งใส

KnowingMind is designed around verifiable source boundaries rather than trust in an AI answer alone.

## Public project transparency

Publicly visible:
- public collaboration source: this repository;
- issues and pull requests;
- release history;
- public-safe tests and CI;
- contribution and governance policies;
- support purpose and public support link.

Not publicly exposed:
- secrets and credentials;
- private runtime details;
- private evidence;
- user practice data;
- donor billing/payment details;
- non-redistributable source material.

## Authority boundaries

- **SOURCE > MODEL**
- AI is not Canon.
- AI is not a spiritual authority.
- Canon, Library, Practice, and AI Analysis must remain distinguishable.
- Software tests verify software behavior; they do not certify Buddhist Canon truth.
- Dhamma claims should carry provenance and appropriate verification status.

## Development transparency

Changes should be reviewable through GitHub issues, pull requests, commits, checks, and release notes.

For material production changes, the project should distinguish:
- proposed;
- merged;
- deployed;
- independently verified.

These states must not be collapsed into a single “done” claim.

## Financial transparency

The public support channel is for project operating costs, including server/infrastructure and AI/service usage.

Recommended public reporting:
- publish aggregate support received by period when reporting is available;
- publish aggregate operating-cost categories;
- never expose individual payment records;
- list supporter names only with explicit opt-in;
- clearly distinguish donations/support from product/service revenue.

## Contributor transparency

Human contributors are credited from public, traceable project evidence. Financial support does not increase technical, doctrinal, or verification authority.

## Security and privacy

Security-sensitive information belongs in private reporting channels. Public transparency does not mean publishing secrets, private infrastructure details, or personal data.
