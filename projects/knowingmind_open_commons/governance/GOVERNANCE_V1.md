# KnowingMind Open Commons Governance V1

## Roles

### Member
Uses the service and may maintain a profile.

### Contributor
Submits code, translations, documentation, content, reviews, or other work.

### Reviewer
Reviews contribution quality and scope.

### Domain Reviewer
Reviews source use, terminology, provenance, and interpretation for a specific knowledge domain.

### Maintainer
Controls source release, technical merge, release, security, and repository operations.

### Independent Verifier
Checks evidence/readback independently from the author or implementing agent.

## Decision classes

Maintainer decision:
- repository configuration,
- release operations,
- technical merge,
- incident response.

Domain-review decision:
- source/provenance adequacy,
- terminology and interpretation classification.

Human-gated decision:
- open-source license finalization,
- public repository visibility,
- live payment activation,
- disputed source rights,
- production connectivity,
- policy changes affecting user rights.

## Non-purchasable authority

Donations, sponsorship, membership tier, or contribution points must not directly grant:

- Canon-verification authority,
- doctrinal override,
- independent-verifier override,
- ability to suppress conflicting evidence,
- automatic moderation immunity.

## Conflict of interest

Reviewers should disclose a material conflict where relevant. A contributor should not be the sole independent verifier of their own high-impact change.

## Change rule

REUSE → MODIFY → CREATE.

Do not create a second identity, points, payment, deployment, or authority system if an existing controlled component can be safely extended.

## Evidence rule

REQUESTED != EXECUTED  
EXECUTION_DONE != VERIFIED_PASS  
SOURCE_COMPLETE != PUBLIC_READY

Public readiness requires explicit evidence and release-gate readback.
