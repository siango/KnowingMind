# License Decision Record V1

Status: PROPOSED — HUMAN GATE REQUIRED

## Proposed model

Project-owned software code:
- Apache License 2.0

Project-owned documentation:
- Creative Commons Attribution 4.0 International (CC BY 4.0)

## Reasoning

Apache-2.0 provides a permissive open-source model with explicit patent provisions.

CC BY 4.0 allows reuse and translation of project-owned documentation with attribution.

## Important exclusions

This decision does not relicense:
- third-party books,
- Canon editions,
- translations owned by others,
- photographs,
- audio/video,
- datasets,
- fonts,
- external APIs or SDKs.

Each third-party asset retains its own license and redistribution restrictions.

## Current repository rule

The current private repository's existing LICENSE remains legally controlling until an authorized maintainer explicitly replaces or supplements it through an approved release action.

This document is a decision proposal, not a license grant.

## Required evidence before approval

- ownership/copyright inventory,
- third-party dependency/license scan,
- source-data rights inventory,
- review of public repository contents,
- maintainer approval record.
