# Contributing

KnowingMindApp is a public-alpha research project for Dhamma-grounded AI.

## Before contributing

- Open an issue before substantial work.
- Keep pull requests small and scoped.
- Never submit secrets, credentials, private evidence, raw PDFs, archives,
  user practice data, or production endpoint details.
- Use mock or synthetic data in examples and tests.
- Do not claim Canon verification from source code or automated tests.
- Dhamma-content changes require a Dhamma review issue.

## Workflow

1. Branch from `main`.
2. Add tests and documentation where applicable.
3. Run the available checks.
4. Complete the pull-request checklist.
5. Wait for required technical, security, and Dhamma review.
