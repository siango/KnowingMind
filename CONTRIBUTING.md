# Contributing

KnowingMind is a public collaboration project for Dhamma-grounded AI.

## Before contributing

- Open an issue before substantial work.
- Keep pull requests small and scoped.
- Never submit secrets, credentials, private evidence, raw restricted source files, archives, user practice data, or production endpoint details.
- Use mock or synthetic data in examples and tests.
- Do not claim Canon verification from source code or automated tests.
- Dhamma-content changes require source citations and domain review.

## Workflow

1. Fork or branch from `main`.
2. Add tests and documentation where applicable.
3. Run available checks.
4. Open a Pull Request with a clear scope.
5. Wait for required technical, security, and Dhamma/domain review.

## Good first contributions

Documentation, tests, accessibility, localization, public UI, provenance tooling, citation handling, and developer experience improvements are suitable starting points.
