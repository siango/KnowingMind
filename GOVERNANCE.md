# Governance

## Purpose

KnowingMind is the public collaboration layer for Dhamma Grounded AI.

## Authority boundaries

- SOURCE > MODEL.
- AI is not Canon.
- AI is not a spiritual authority.
- Canon, Library, Practice, and AI Analysis should remain distinguishable.
- Automated tests may verify software behavior, not Buddhist Canon truth.
- Unsupported quotations must not be presented as authentic.
- AI must not issue spiritual-attainment certification.

## Decision classes

- **Maintainers**: source, release, security, and repository decisions.
- **Dhamma/domain reviewers**: claims, citations, transformations, and presentation.
- **Independent verifier**: evidence/readback checks separate from the author when required.
- **Human gate**: licensing, public release, production connectivity, live payment enablement, and disputed Dhamma interpretations.

## Change policy

Prefer **REUSE → MODIFY → CREATE**. Do not publish private production infrastructure merely because public application code is available.

## Public release rule

A public contribution is not automatically production-ready. Security, rights, licensing, public/private boundary, reproducibility, and independent verification remain separate concerns.
